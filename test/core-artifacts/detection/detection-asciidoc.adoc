= Statement detection: AsciiDoc

The built-in AsciiDoc fileType reads the `// (test …)` grammar; plain comments
stay inert, and statements inside listing blocks run as they always have.

// just a regular comment, not a statement

// (test {"testId": "detection-asciidoc-comments"})

Check the docs server at http://localhost:8092[the test server].

// (step {"checkLink": "http://localhost:8092"})
// (step {"wait": 100})

// (test ignore start)
// (step {"httpRequest": {"url": "http://localhost:9/unreachable"}})
// (test ignore end)

// (step {"wait": 10})
----
