## v3.4.0

### New features

- Added [DITA](/docs/test-docs/input-formats/dita) as a built-in file type for `.dita`, `.ditamap`, and `.xml` files, and added it to the default `fileTypes`. Write inline tests and steps as `<?doc-detective test ?>` processing instructions or as XML comments.
- Doc Detective detects steps in DITA content, such as `<uicontrol>` elements to click or find, `<xref>` links to check or open, and code blocks to run.
