Each entry lists what changed for you in one Doc Detective release. New features come first, then behavior and breaking changes, then notable bug fixes. Releases that only changed internals say so in one line. Entries start at version 3.0.0, with the newest release first. Major releases lead with their breaking changes and migration steps. To find your installed version, run `npx doc-detective --version`.

Moving to Doc Detective 5? Start with [Upgrade to Doc Detective 5](/docs/ci/upgrade-to-v5).

For commit-level detail, including changes to build and test tooling, see the [GitHub releases](https://github.com/doc-detective/doc-detective/releases) for Doc Detective.
