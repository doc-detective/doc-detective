## v3.2.0

### New features

- Added the [`saveCookie`](/docs/actions/savecookie) and [`loadCookie`](/docs/actions/loadcookie) actions. Save a browser cookie to a file or an environment variable, then load it into the browser in a later step or test.
- With `logLevel` set to `debug`, the CLI prints its version information and the resolved config before it runs tests.
