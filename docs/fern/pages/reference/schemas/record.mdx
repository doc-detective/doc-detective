## Fields

Field | Type | Description | Default
:-- | :-- | :-- | :--
record | one of:<br/>- string<br/>- object([Record (detailed)](/reference/schemas/record-detailed))<br/>- boolean | Required. Start recording. A later `stopRecord` step stops it, and Doc Detective stops any recording still running when the test context ends. The `browser` engine captures the Chrome viewport (works under concurrency); the `ffmpeg` engine captures the screen and supports any application. On Android/iOS contexts, recording captures the device screen through the device itself — `engine` doesn't apply. Supported extensions, in any case: `.mp4`, `.webm`, and `.gif`. | —
