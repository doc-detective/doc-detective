## Fields

Field | Type | Description | Default
:-- | :-- | :-- | :--
mockRequest | object([mockRequest](/reference/schemas/mockrequest)) | Required. Answer matching browser requests with a fixed response, a sequence of responses, or the responses recorded in a HAR file, from this step until the test ends. A later `mockRequest` for the same `url` and `method` replaces the earlier one. Runs only in Chrome. In other browsers, the step is skipped. | —
