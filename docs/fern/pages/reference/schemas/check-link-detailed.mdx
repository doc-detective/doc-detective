Check if an HTTP or HTTPS URL returns an acceptable status code from a GET request.

## Referenced In

- [checkLink](/reference/schemas/checklink)

## Fields

Validation applies the defaults shown here.

Field | Type | Description | Default
:-- | :-- | :-- | :--
url | string | Required. An absolute `http://` or `https://` URL, a path that starts with `/`, or a value that starts with an environment variable, such as `$BASE_URL/docs`. A path is joined to `origin`.<br/><br/>Pattern: `^(https?://|/|\$[A-Za-z0-9_]+)` | —
origin | string | Optional. Protocol and domain to join to a `url` that starts with `/`. Overrides `origin` in the config. | —
params | object | Optional. Query parameters to append to the resolved URL. Merged on top of `originParams` from config; step keys win on collision. If `url` already contains a colliding query key, the value here replaces it. Values support environment variable substitution via `$VAR` syntax. WARNING: values are embedded in the request URL and appear in test results, logs, and reports. | ``{}``
statusCodes | one of:<br/>- integer<br/>- array of integer | Optional. Accepted status codes. If the specified URL returns a code other than what is specified here, the action fails. A single integer is treated as a one-item list. | ``[200,301,302,307,308]``
headers | one of:<br/>- object<br/>- string | Optional. Additional HTTP headers to include in the request: an object with string values, or a string with one `Name: value` header per line. Merged on top of Doc Detective's default browser-mimicking headers. Useful for sites behind bot protection or WAFs that allowlist specific headers (for example, a Cloudflare Access service token or a `Cookie` with a `cf_clearance` value). | ``{}``
