## Fields

Validation applies the defaults shown here.

Field | Type | Description | Default
:-- | :-- | :-- | :--
path | string | Optional. Glob for the file to wait for. A relative path resolves against the spec file. When several files match, the newest finished one counts.<br/><br/>Minimum length: 1 | —
download | string | Optional. Glob for a file name in the context's download folder. Each `checkFile` returns the oldest finished download that no earlier `checkFile` in the context returned. Needs a desktop Chrome or Firefox context opened by an earlier step. In other contexts, the step is skipped.<br/><br/>Minimum length: 1 | —
content | string | Optional. Text the file must contain, read as UTF-8. A value that starts and ends with `/` is a regular expression. | —
timeout | integer | Optional. Maximum time in milliseconds to wait for a finished match.<br/><br/>Minimum: 1 | `30000`
