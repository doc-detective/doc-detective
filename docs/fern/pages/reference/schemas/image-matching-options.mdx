Defaults for the visual element-matching (`image`) finding criterion.

## Referenced In

- [config](/reference/schemas/config)

## Fields

Field | Type | Description | Default
:-- | :-- | :-- | :--
matchThreshold | number | Required. Default minimum normalized match score (0–1) for the `image` finding criterion. Higher is stricter: 1 demands a near pixel-perfect match, lower values tolerate more rendering variation but risk matching lookalikes. Individual steps override this with their own `matchThreshold`.<br/><br/>Minimum: 0. Maximum: 1 | `0.8`

## Examples

```json
{
  "matchThreshold": 0.8
}
```
