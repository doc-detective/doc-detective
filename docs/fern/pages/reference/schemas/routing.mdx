A single routing entry on a test handler (`onPass`, `onFail`, `onWarning`, `onSkip`): an optional condition (`if`) plus exactly one of `continue`, `stop` (`test` or `spec`), or `goToTest`. Step handlers take a step routing entry instead.

## Referenced In

- [test](/reference/schemas/test)

## Fields

Field | Type | Description | Default
:-- | :-- | :-- | :--
if | one of:<br/>- string<br/>- array of string | Optional. A condition expression, or an array of expressions combined with logical AND. | —
continue | `true` | Optional. Continue with the next test. Use to explicitly suppress a default handler behavior. | —
stop | string | Optional. Stop at the given scope. `test` does nothing, because the test already finished. `spec` skips the spec's remaining tests.<br/><br/>Accepted values: `test`, `spec` | —
goToTest | string | Optional. Identifier of the test to jump to, within the same spec.<br/><br/>Minimum length: 1. Pattern: `\S` | —

## Examples

```json
{
  "continue": true
}
```

```json
{
  "stop": "spec"
}
```

```json
{
  "if": "$$platform == windows",
  "goToTest": "cleanup"
}
```
