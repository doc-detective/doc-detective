## Fields

Field | Type | Description | Default
:-- | :-- | :-- | :--
path | string | Optional. Path to a PNG, JPEG, or SVG file. A relative path resolves against the spec file, unless `relativePathBase` is `cwd`.<br/><br/>Minimum length: 1. Pattern: `\S` | —
base64 | string | Optional. The image's bytes as base64, with or without a `data:image/png;base64,` prefix. Failure messages call it `base64 reference` rather than printing the value.<br/><br/>Minimum length: 1. Pattern: `\S` | —
threshold | number | Optional. The lowest score that counts as a match. A location's score is the lower of its shape score and its color score, and 1 is a perfect match. Defaults to 0.9.<br/><br/>Exclusive minimum: 0. Maximum: 1 | —
color | string | Optional. The icon's color on the page, as a six-digit hex value. Use this for a file drawn in `currentColor`, which renders black, or to find a one-color icon in another color. Works only with a transparent file in one color.<br/><br/>Pattern: `^#[0-9a-fA-F]{6}$` | —
