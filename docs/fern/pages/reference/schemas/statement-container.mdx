Nodes of one selector kind to read as statements.

## Referenced In

- [Inline statement definition](/reference/schemas/inline-statement-definition)

## Fields

Field | Type | Description | Default
:-- | :-- | :-- | :--
comment | object | Optional. Selects comments. | —
codeBlock | one of:<br/>- string<br/>- object | Optional. Selects code blocks. A string selects one language. | —
link | object | Optional. Selects links. | —
image | object | Optional. Selects images. | —
strong | object | Optional. Selects bold text. | —
emphasis | object | Optional. Selects italic text. | —
text | object | Optional. Selects runs of prose, outside code, links, and formatting. | —
element | one of:<br/>- string<br/>- object | Optional. Selects elements, such as HTML tags, XML elements, and JSX components. A string selects one tag. | —
value | string | Optional. Field that holds the statement text. Defaults to the node's main text.<br/><br/>Pattern: `^(content|text|language|meta|url|title|src|alt|tag|attributes\.\S+|match\.\d+|precededBy\.\d+)$` | —
regex | one of:<br/>- string<br/>- array of string | Optional. Regular expressions to run on the statement text. The first group of the first match becomes the statement, else the whole match. A node that doesn't match isn't a statement. | —

## Examples

```json
{
  "comment": {
    "excludes": "draft"
  },
  "regex": "^dd:\\s*(.*)$"
}
```

```json
{
  "element": {
    "tag": [
      "meta"
    ],
    "attributes": {
      "name": "^doc-detective$"
    }
  },
  "value": "attributes.content"
}
```
