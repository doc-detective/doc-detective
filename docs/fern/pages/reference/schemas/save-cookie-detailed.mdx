## Fields

Validation applies the defaults shown here.

Field | Type | Description | Default
:-- | :-- | :-- | :--
name | string | Required. Name of the specific cookie to save.<br/><br/>Pattern: `^[A-Za-z0-9_.-]+$` | —
variable | string | Optional. Environment variable name to store the cookie as JSON string. To read it later as `$NAME`, use only letters, digits, and underscores.<br/><br/>Pattern: `^[A-Za-z0-9_.-]+$` | —
path | string | Optional. File path to save the cookie, in Netscape cookie format. A relative path resolves against `directory`, or against `outputDir` when `directory` is omitted.<br/><br/>Minimum length: 1. Pattern: `\S` | —
directory | string | Optional. Directory to save the cookie file in. A relative directory resolves against the spec file. Omit it to save under `outputDir`.<br/><br/>Minimum length: 1. Pattern: `\S` | —
overwrite | boolean | Optional. Whether to overwrite existing cookie file. | `false`
domain | string | Optional. Specific domain to filter the cookie by (optional). | —
