= Compare pages in tabs, windows, and sessions

. Start at http://localhost:8092/multi-tab.html[the multi-tab page].
. Click the Open child in new tab link. The child page opens in a new tab.
. In the newest tab, check that the page reads "PAGE linked".
. In a new tab named `report`, load http://localhost:8092/multi-tab-child.html?page=report[the report page].
. In a new window named `settings`, load http://localhost:8092/multi-tab-child.html?page=settings[the settings page].
. Start a second Firefox session named `reviewer`, with an 800 by 600 viewport, and load http://localhost:8092/multi-tab-child.html?page=review[the review page] in it.
. In the first tab of the first session, check that the page still reads "MULTI-TAB HOME".
. Close the child tab, the `report` tab, the `settings` window, and the `reviewer` session.
