= Reuse a signed-in browser state

Run these steps in Firefox and in Chrome.

. Sign in at http://localhost:8092/cookies/set/sessions_state/signed-in[the sign-in page]. The server sets the `sessions_state` cookie.
. Save the browser state to `sessions-state.json`.
. Go to http://localhost:8092/cookies/set/sessions_state/signed-out[the sign-out page], which replaces the cookie.
. Load the browser state from `sessions-state.json`.
. Go to http://localhost:8092/cookies[the cookie report], and check that it shows *sessions_state=signed-in*.
