Reuse a signed-in browser state

Run these steps in Firefox and in Chrome.

  1. Sign in at the sign-in page. The server sets the sessions_state cookie.
  2. Save the browser state to sessions-state.json.
  3. Go to the sign-out page, which replaces the cookie.
  4. Load the browser state from sessions-state.json.
  5. Go to the cookie report, and check that it shows sessions_state=signed-in.
