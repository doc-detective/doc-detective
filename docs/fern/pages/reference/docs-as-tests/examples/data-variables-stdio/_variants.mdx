# Save the Node.js version

1. Print the Node.js version:

   ```shell
   node --version
   ```
2. Check that the saved version starts with `v`:

   ```shell
   node -e "process.exit(process.env.NODE_VERSION.startsWith('v') ? 0 : 1)"
   ```
