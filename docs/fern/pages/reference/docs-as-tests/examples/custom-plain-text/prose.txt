Create a user with the echo API

INCLUDE prerequisites.txt

1. Send a POST request to http://localhost:8092/api/users with the body {"name":"Ada"}.
   The API returns the user it created.

To remove a user later, send a request like this one. Don't run it against
data you want to keep:
   Send a DELETE request to http://localhost:8092/api/users/1 with the body {"confirm":true}.
