These pages show how documentation becomes tests. Each example takes one procedure and shows it four ways:

| Tab | What the file holds |
|---|---|
| Prose | The documentation as a reader sees it, with no test statements. |
| Detected | The same prose inside a `test` statement. Default detection turns links, bold text, quoted text, images, and code blocks into steps. A `step` statement covers anything detection can't find. |
| Inline | The same prose with a `step` statement after each instruction, and detection off. |
| Standalone | A spec file, in JSON or YAML, with no documentation source. |

Each text tab holds Markdown, MDX, AsciiDoc, HTML, reStructuredText, and DITA, unless a format can't express the feature. The page then says why. Every file is real, and Doc Detective runs each one. A check confirms that the inline and standalone variants resolve to the same steps, and that the detected variants agree with each other.

For how each mode works, see [Detected tests](/docs/test-docs/detected), [Inline tests](/docs/test-docs/inline), and [Standalone tests](/docs/test-docs/standalone).

## What each mode can express

| Feature | Detected | Inline | Standalone |
|---|---|---|---|
| Open, check, click, find, and type from links, bold text, and quoted text | From the prose | A `step` statement | A step |
| Screenshots from an image with the `screenshot` class | From the prose | A `step` statement | A step |
| HTTP requests from an `http` code block, and code from a `bash`, `python`, or `javascript` code block | From the prose | A `step` statement | A step |
| DITA `<uicontrol>`, `<wintitle>`, `<xref>`, and `<link>` | From the prose, DITA only | A `step` statement | A step |
| Every other action and option, such as `wait`, `record`, `startSurface`, and `dragAndDrop` | A `step` statement | A `step` statement | A step |
| Test fields, such as `runOn`, `if`, `onFail`, and `publicVariables` | The `test` statement | The `test` statement | The test |
| Test `before` and `after` | Not available | Not available | The test |
