title: saveCookie

The `saveCookie` action saves a browser cookie to a file or environment variable for later reuse. This action is useful for preserving authentication sessions, user preferences, or other stateful information between test runs or across different tests.

Reload saved cookies with the [`loadCookie`](/docs/actions/loadcookie) action.

A cookie file holds the real cookie value, because `loadCookie` reads it back. Unlike the output files that actions such as `runShell`, `runCode`, and `httpRequest` save with `path`, it isn't masked. An authentication cookie works like a password. Add the cookie file's folder (`directory`, or `outputDir` by default) to `.gitignore`, and leave it out of uploaded CI artifacts.

A cookie saved with `variable` holds the real value too. Saving it doesn't register it for masking, even when the variable's name looks secret. Logs and reports mask it only after a later step substitutes it as `$NAME` in one of its fields. Loading the cookie with `loadCookie` doesn't register it for masking. A `runShell` or `runCode` command that reads the variable from its environment prints the real cookie, so don't print or dump the environment in those commands. See [Keep secrets out of logs, reports, and captures](/docs/ci/secrets).

> For comprehensive options, see the [`saveCookie`](/reference/schemas/savecookie) reference.

## Use cases

- **Session persistence**: Save authentication cookies to maintain login state across test runs
- **Multi-step workflows**: Preserve cookies between different test specifications
- **Cross-browser testing**: Transfer cookies between different browser contexts
- **CI/CD integration**: Store authentication state as environment variables for automated testing
- **Test data management**: Save cookies to files for debugging and test data inspection

## Formats

The `saveCookie` action supports multiple formats:

### String format

A cookie name saves that cookie to the environment variable of the same name. A path ending in `.txt` saves the cookie named for the file, `session_token` here, to that path in `outputDir`:

```json title="Save to environment variable"
{
  "saveCookie": "session_token"
}
```

```json title="Save to file"
{
  "saveCookie": "session_token.txt"
}
```

### Object format

Save a cookie with detailed configuration:

```json
{
  "saveCookie": {
    "name": "auth_cookie",
    "path": "auth-session.txt",
    "directory": "./test-data",
    "overwrite": "true"
  }
}
```

## Configuration options

| Field | Type | Description | Default |
|-------|------|-------------|---------|
| `name` | string | **Required.** Name of the specific cookie to save. | |
| `variable` | string | Environment variable name to store the cookie as JSON string. Can't be used with `path`. | |
| `path` | string | File path to save the cookie, in Netscape cookie format. A relative path resolves against `directory`, or against `outputDir` when `directory` is omitted. Can't be used with `variable`. | |
| `directory` | string | Directory to save the cookie file in. A relative directory resolves against the spec file. | `outputDir` |
| `overwrite` | boolean | Whether to overwrite an existing cookie file. | `false` |
| `domain` | string | Specific domain to filter the cookie by (optional). | |

## Examples

### Save to default location


### Save to specific file

```json
{
  "steps": [
    {
      "description": "Save authentication cookie to specific file",
      "saveCookie": {
        "name": "auth_cookie",
        "path": "auth-session.txt",
        "directory": "./test-data",
        "overwrite": "true"
      }
    }
  ]
}
```

### Save to environment variable

{/* test {"testId":"savecookie-object-variable","detectSteps":false} */}

```json
{
  "steps": [
    {
      "description": "Save session cookie to environment variable",
      "saveCookie": {
        "name": "session_token",
        "variable": "SESSION_TOKEN"
      }
    }
  ]
}
```

{/* step {"stepId":"goto-savecookie-object","description":"Open the local test server","goTo":"http://localhost:8092"} */}
{/* step {"stepId":"set-cookie-object","description":"Set a cookie in the browser to save","runBrowserScript":"document.cookie = 'session_token=xyz789; path=/;';"} */}
{/* step {"stepId":"savecookie-object","description":"Save the cookie to a named environment variable (object format)","saveCookie":{"name":"session_token","variable":"DD_DOCS_SESSION_TOKEN"}} */}
{/* step {"stepId":"verify-savecookie-object","description":"Confirm the cookie value landed in the named environment variable","runCode":{"language":"javascript","code":"console.log(process.env.DD_DOCS_SESSION_TOKEN);","stdio":"/xyz789/"}} */}
{/* test end */}

### Save with domain filtering

{/* test {"testId":"savecookie-domain-filter","detectSteps":false} */}

```json
{
  "steps": [
    {
      "description": "Save cookie for specific domain",
      "saveCookie": {
        "name": "login_token",
        "path": "login-token.txt",
        "domain": "app.example.com"
      }
    }
  ]
}
```

{/* step {"stepId":"goto-savecookie-domain","description":"Open the local test server","goTo":"http://localhost:8092"} */}

{/* step {"stepId":"verify-savecookie-domain","description":"Confirm the domain-filtered cookie value landed in the environment variable","runCode":{"language":"javascript","code":"console.log(process.env.DD_DOCS_LOGIN_TOKEN);","stdio":"/domain-filtered-456/"}} */}
{/* test end */}
