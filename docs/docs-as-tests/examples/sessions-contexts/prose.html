Check what the page sees in an emulated browser

Run these steps in headless Chrome set to dark mode, German, Berlin time, a 2x display, reduced motion, and a fixed clock.

  1. Start at the test site's home page.
  2. Check that the page prefers the dark color scheme and reduced motion.
  3. Check that the page's language is de-DE and its time zone is Europe/Berlin.
  4. Check that the device pixel ratio is 2, and that the clock reads 3 December 2026, 09:00 UTC.
