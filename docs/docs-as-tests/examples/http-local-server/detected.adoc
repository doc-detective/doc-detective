= Run a local server

// (test {"testId":"http-local-server","detectSteps":true})

Start the sample API server. It takes the port as an argument and prints `Listening` when it's ready:

[source,js,testIgnore]
----
const http = require("http");
const port = Number(process.argv[2]);
http.createServer((req, res) => res.end("ok")).listen(port, () => console.log("Listening"));
----

// (step {"runCode":{"language":"js","code":"const http = require(\"http\");\nconst port = Number(process.argv[2]);\nhttp.createServer((req, res) => res.end(\"ok\")).listen(port, () => console.log(\"Listening\"));","args":["8231"],"background":{"name":"http-local-api","waitUntil":{"port":8231,"stdio":"Listening","httpGet":"http://localhost:8231/health","delayMs":100}},"timeout":15000}})

Check the server's health endpoint at `http://localhost:8231/health`. It returns `ok`.

// (step {"httpRequest":{"url":"http://localhost:8231/health","statusCodes":200,"response":{"body":"ok"}}})

Stop the server when you're done.

// (step {"closeSurface":"http-local-api"})

To start a quick server from your shell instead, run:

[source,shell]
----
node -e "require('http').createServer((q, r) => r.end('ok')).listen(8232)"
----

// (step {"runShell":{"command":"node -e \"require('http').createServer((q, r) => r.end('ok')).listen(8232)\"","background":{"name":"http-local-shell","tty":true,"waitUntil":{"port":8232,"httpGet":"http://localhost:8232/"}},"timeout":15000}})

Stop it the same way.

Terminal apps size their output to the terminal. To see the size an app gets in a 100-by-40 terminal, run:

[source,shell]
----
node -e "console.log('Terminal: ' + process.stdout.columns + 'x' + process.stdout.rows); setInterval(() => {}, 1000);"
----

// (step {"runShell":{"command":"node -e \"console.log('Terminal: ' + process.stdout.columns + 'x' + process.stdout.rows); setInterval(() => {}, 1000);\"","background":{"name":"http-local-tty","tty":{"cols":100,"rows":40},"waitUntil":{"stdio":"Terminal: 100x40"}},"timeout":30000}})
