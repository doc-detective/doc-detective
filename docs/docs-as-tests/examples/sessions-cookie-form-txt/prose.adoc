= Keep a cookie in a file

. Delete any `sessions_ptxt.txt` that an earlier run left in the output folder.
. Sign in at http://localhost:8092/cookies/set/sessions_ptxt/signed-in[the sign-in page]. The server sets the `sessions_ptxt` cookie.
. Save the `sessions_ptxt` cookie to `sessions_ptxt.txt`.
. Sign out at http://localhost:8092/cookies/set/sessions_ptxt/signed-out[the sign-out page], which replaces the cookie.
. Load the cookie from `sessions_ptxt.txt`.
. Open http://localhost:8092/cookies[the cookie report], and check that it shows *sessions_ptxt=signed-in*.
