Point out the controls on a toolbar
===================================

#. Go to `the toolbar page <http://localhost:8092/find-image.html>`_.

#. Find the save button, marked 1, and the green check icon, outlined.

#. The status line at the top is hidden, because it changes on every visit.

#. Compare your toolbar with the screenshot.

#. Next, find the check icon, now marked 2.

#. That's every control on the toolbar.
