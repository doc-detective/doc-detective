= Open a named window with a named tab

. Start at http://localhost:8092/multi-tab.html[the multi-tab page].
. Load http://localhost:8092/multi-tab-child.html?page=report[the report page] in a new tab named `report`.
. Load http://localhost:8092/multi-tab-child.html?page=settings[the settings page] in a new window named `settings`, with its first tab named `general`.
. Check that the `general` tab of the `settings` window reads "PAGE settings".
