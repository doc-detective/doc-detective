Keep the cookie for one domain

  1. Sign in at the sign-in page. The server sets the sessions_pdomain cookie.
  2. Save the localhost cookie named sessions_pdomain to sessions_pdomain.txt.
  3. Sign out at the sign-out page, which replaces the cookie.
  4. Load the localhost cookie from sessions_pdomain.txt.
  5. Open the cookie report, and check that it shows sessions_pdomain=signed-in.
