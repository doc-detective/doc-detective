= Compare pages in tabs, windows, and sessions

. Start at http://localhost:8092/multi-tab.html[the multi-tab page].
. Click the Open child in new tab link. The child page opens in a new tab.
. In the newest tab, check that the page reads "PAGE linked".
. In a new tab named `report`, load http://localhost:8092/multi-tab-child.html?page=report[the report page]. Then load http://localhost:8092/multi-tab-child.html?page=scratch[the scratch page] in another new tab.
. Check that the `report` tab reads "PAGE report", and that the tab showing the scratch page reads "PAGE scratch".
. In a new window named `settings`, with its first tab named `general`, load http://localhost:8092/multi-tab-child.html?page=settings[the settings page]. Then load http://localhost:8092/multi-tab-child.html?page=help[the help page] in another new window.
. Check that the `settings` window and its `general` tab read "PAGE settings", and that the newest window, titled "Child help", reads "PAGE help".
. In the first window, check that the tab titled "Multi-tab home" still reads "MULTI-TAB HOME".
. Type `hello` in the echo box of the help window, which is also the newest window, and of the child tab, the second tab opened.
. Load http://localhost:8092/multi-tab-child.html?page=notes[the notes page] in a new tab named `notes`, and http://localhost:8092/multi-tab-child.html?page=about[the about page] in a new window named `about`. Check that each one reads its page name.
. Start two more Firefox sessions: `reviewer`, with an 800 by 600 viewport, and `editor`, with a 1024 by 768 window. Load http://localhost:8092/multi-tab-child.html?page=review[the review page] in `reviewer`.
. In the first session, go back to http://localhost:8092/multi-tab.html[the multi-tab page], and check that it reads "MULTI-TAB HOME".
. Close the `report` and `notes` tabs, the scratch tab, the child tab, the help, `settings`, and `about` windows, and the `reviewer` and `editor` sessions.
