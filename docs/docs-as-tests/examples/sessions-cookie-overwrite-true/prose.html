Replace a saved cookie

  1. Sign in at the sign-in page. The server sets the sessions_pover cookie.
  2. Save the sessions_pover cookie to sessions_pover.txt, replacing any earlier file.
  3. Sign in again at the second sign-in page, and save the cookie to the same file.
  4. Sign out at the sign-out page, which replaces the cookie.
  5. Load the cookie from sessions_pover.txt.
  6. Open the cookie report, and check that it shows sessions_pover=second.
