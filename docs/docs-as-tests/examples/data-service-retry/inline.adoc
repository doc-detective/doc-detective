== Echo text

. Go to http://localhost:8092/type-echo.html[the type echo page].
+
// (step {"goTo":"http://localhost:8092/type-echo.html"})
. Click *Type here:*.
+
// (step {"click":"Type here:"})
. Type "Hello, Doc Detective".
+
// (step {"type":"Hello, Doc Detective"})
. Check that the page shows *Hello, Doc Detective* below the field. If it doesn't, type the text again.
+
// (step {"stepId":"read-echo","find":{"selector":"#echo","elementText":"Hello, Doc Detective"},"variables":{"ECHOED":"$$element.text"},"onPass":[{"if":["$$outputs.element.text == \"Hello, Doc Detective\""],"goToStep":"send-echo"}],"onFail":[{"retry":{"limit":2,"delay":500}}]})
+
// (step {"stepId":"retype","type":"Hello, Doc Detective"})
. Send the text to the messages API. Send a `+POST+` request to `+http://localhost:8093/api/messages+` with this body:
+
[source,json]
----
{"text": "Hello, Doc Detective"}
----
+
The API returns the same text.
+
// (step {"stepId":"send-echo","if":"$$steps.read-echo.outputs.element.text == \"Hello, Doc Detective\"","httpRequest":{"url":"http://localhost:8093/api/messages","method":"post","request":{"body":{"text":"$ECHOED"}},"response":{"body":{"text":"Hello, Doc Detective"}}},"assertions":"$$outputs.response.body.text == \"$ECHOED\"","onWarning":[{"continue":true}]})

// (test end)
