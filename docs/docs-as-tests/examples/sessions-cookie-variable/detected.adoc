= Keep a cookie in a named variable

// (test {"testId":"sessions-cookie-variable","detectSteps":true})

. Sign in at http://localhost:8092/cookies/set/sessions_pvar/signed-in[the sign-in page]. The server sets the `sessions_pvar` cookie.
+
// (step {"goTo":"http://localhost:8092/cookies/set/sessions_pvar/signed-in"})
. Save the `sessions_pvar` cookie to the `SESSIONS_PVAR` environment variable.
+
// (step {"saveCookie":{"name":"sessions_pvar","variable":"SESSIONS_PVAR"}})
. Sign out at http://localhost:8092/cookies/set/sessions_pvar/signed-out[the sign-out page], which replaces the cookie.
+
// (step {"goTo":"http://localhost:8092/cookies/set/sessions_pvar/signed-out"})
. Load the cookie from `SESSIONS_PVAR`.
+
// (step {"loadCookie":{"name":"sessions_pvar","variable":"SESSIONS_PVAR"}})
. Open http://localhost:8092/cookies[the cookie report], and check that it shows *sessions_pvar=signed-in*.
