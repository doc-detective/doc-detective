Keep a cookie in a named variable

  1. Sign in at the sign-in page. The server sets the sessions_pvar cookie.
  2. Save the sessions_pvar cookie to the SESSIONS_PVAR environment variable.
  3. Sign out at the sign-out page, which replaces the cookie.
  4. Load the cookie from SESSIONS_PVAR.
  5. Open the cookie report, and check that it shows sessions_pvar=signed-in.
