# Echo text back

1. Go to [the type echo page](http://localhost:8092/type-echo.html).
2. Click **Type here:**.
3. Type "Hello, Markdown".
4. Check that the page shows **Hello, Markdown** below the field.

To fetch the page from a terminal instead, run:

```bash testIgnore
curl http://localhost:8092/type-echo.html
```
