Find Node.js, then check the API
================================

Find Node.js on Windows
-----------------------

#. Find the Node.js executable:

   .. code-block:: shell

      where node

Check the cart
--------------

#. Send a ``GET`` request to ``http://localhost:8092/api/carts``.

Check the products
------------------

#. Send a ``GET`` request to ``http://localhost:8092/api/products``.
