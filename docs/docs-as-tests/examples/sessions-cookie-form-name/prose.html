Keep a cookie in an environment variable

  1. Sign in at the sign-in page. The server sets the sessions_pname cookie.
  2. Save the sessions_pname cookie to the sessions_pname environment variable.
  3. Sign out at the sign-out page, which replaces the cookie.
  4. Load the cookie from the sessions_pname environment variable.
  5. Open the cookie report, and check that it shows sessions_pname=signed-in.
