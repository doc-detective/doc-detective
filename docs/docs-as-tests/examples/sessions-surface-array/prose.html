Compare two Node.js REPLs

  1. Start two node -i processes, sessions-pleft and sessions-pright, and wait for both prompts.
  2. In sessions-pleft, enter 40 + 2 and press Enter. Wait for the REPL to print 42.
  3. In sessions-pright, enter 6 * 7 and press Enter. Wait for the REPL to print 42.
  4. Close both REPLs.
