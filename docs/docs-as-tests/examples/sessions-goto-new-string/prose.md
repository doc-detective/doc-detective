# Open named tabs and windows

1. Start at [the multi-tab page](http://localhost:8092/multi-tab.html).
2. Load [the notes page](http://localhost:8092/multi-tab-child.html?page=notes) in a new tab named `notes`.
3. Check that the `notes` tab reads "PAGE notes".
4. Load [the about page](http://localhost:8092/multi-tab-child.html?page=about) in a new window named `about`.
5. Check that the new window reads "PAGE about".
