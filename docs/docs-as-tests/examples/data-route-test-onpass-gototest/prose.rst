Check the API, then the shop
============================

Check the API
-------------

#. Send a ``GET`` request to ``http://localhost:8092/api/health``.

Check the cart
--------------

#. Send a ``GET`` request to ``http://localhost:8092/api/carts``.

Check the products
------------------

#. Send a ``GET`` request to ``http://localhost:8092/api/products``.
