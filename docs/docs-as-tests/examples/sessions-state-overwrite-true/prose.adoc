= Replace a saved browser state

. Sign in at http://localhost:8092/cookies/set/sessions_pstateo/signed-in[the sign-in page]. The server sets the `sessions_pstateo` cookie.
. Save the browser state to `sessions-pstateo.json`, replacing any earlier file.
. Sign out at http://localhost:8092/cookies/set/sessions_pstateo/signed-out[the sign-out page], which replaces the cookie.
. Load the browser state from `sessions-pstateo.json`.
. Open http://localhost:8092/cookies[the cookie report], and check that it shows *sessions_pstateo=signed-in*.
