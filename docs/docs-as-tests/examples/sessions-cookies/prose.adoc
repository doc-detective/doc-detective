= Keep a session cookie

. Sign in at http://localhost:8092/cookies/set/sessions_demo/signed-in[the sign-in page]. The server sets the `sessions_demo` cookie.
. Save the `sessions_demo` cookie four ways. Save it to the `sessions_demo` and `SESSIONS_DEMO_COOKIE` environment variables, and to `sessions_demo.txt` in the output folder. Save it to `sessions_demo.txt` in a `tmp` folder next to this file, keeping only the `localhost` cookie.
. Go to http://localhost:8092/cookies/set/sessions_demo/signed-out[the sign-out page], which replaces the cookie.
. Load the cookie from `sessions_demo.txt` in the output folder.
. Go to http://localhost:8092/cookies[the cookie report], and check that it shows *sessions_demo=signed-in*.
. Go to http://localhost:8092/cookies/set/sessions_demo/signed-out[the sign-out page] again, and load the cookie from the `SESSIONS_DEMO_COOKIE` environment variable.
. Go to http://localhost:8092/cookies[the cookie report] again, and check that it shows *sessions_demo=signed-in*.
. Go to http://localhost:8092/cookies/set/sessions_demo/signed-out[the sign-out page] once more, and load the `localhost` cookie from `tmp/sessions_demo.txt`.
. Go to http://localhost:8092/cookies[the cookie report] a last time, and check that it shows *sessions_demo=signed-in*.
